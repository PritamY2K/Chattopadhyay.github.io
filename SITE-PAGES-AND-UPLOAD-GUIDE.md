# Complete Multi-page Website

This package contains the complete academic website of Dr. Pritam Chattopadhyay.

## Website pages

1. `index.html` — Home
2. `about.html` — Academic profile and expertise
3. `research.html` — Research themes
4. `projects.html` — Software tools and applications
5. `publications.html` — Publications and books
6. `innovation.html` — Products and innovation
7. `teaching.html` — Semester-wise and paper-wise teaching materials
8. `contact.html` — Contact and collaboration information

## Teaching catalogue

The Teaching page contains 23 B.Sc. Botany papers covering Semesters I–VIII.
The catalogue is controlled by:

- `assets/courses.js`
- `assets/teaching.js`
- `materials/initial-course-catalogue.csv`

## Uploading to GitHub

1. Extract this ZIP file.
2. Open the extracted folder.
3. Select every file and folder inside it.
4. Open the repository `PritamY2K/Chattopadhyay.github.io`.
5. Choose **Add file → Upload files**.
6. Upload all selected items.
7. Allow GitHub to replace files with matching names.
8. Commit directly to the `main` branch.

Suggested commit message:

`Add complete multi-page website and teaching catalogue`

The public website address is:

`https://pritamy2k.github.io/Chattopadhyay.github.io/`
