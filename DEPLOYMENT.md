# Deploying the multi-page website

1. Extract the ZIP package.
2. Upload **all files and folders inside** `Chattopadhyay-multipage-website` to the repository root.
3. Replace the existing files when GitHub reports matching names.
4. Commit directly to the `main` branch.
5. GitHub Pages will redeploy automatically from `main` and `/(root)`.

Public address:

`https://pritamy2k.github.io/Chattopadhyay.github.io/`

## Important

Upload the HTML files directly to the repository root. Do not place them inside another folder.
